# Kali 30 天入门计划：零基础每日实操

这份计划面向零基础，把 Kali 实操和网络、Web、Linux 的基础知识放在一起学。每天的内容拆成三部分：命令和用途、配套知识点、当天目标。不看视频，纯动手，目的是学完能独立完成一些基础操作，而不是只会照着抄命令。

需要提前说明：本计划偏实操，理论部分不会讲得太深。

---

## 第 1 周：Linux 基础 + 网络常识

### 第 1 天

**实操**

```bash
whoami          # 查看当前登录用户
pwd             # 查看当前所在目录
ls              # 列出当前目录下的文件
ls -la          # 列出所有文件，包括隐藏文件
```

**配套知识**

IP 地址是设备在网络里的地址，比如 `192.168.1.10`。局域网就是同一个 WiFi 或同一个虚拟机网段里的设备，彼此之间可以互相访问。

**今日目标**：看懂自己的身份和位置，知道 IP 是设备地址。

### 第 2 天

**实操**

```bash
mkdir test_dir          # 新建文件夹
touch test.txt          # 新建空文本文件
nano test.txt           # 编辑文件，Ctrl+O 保存，Ctrl+X 退出
cat test.txt            # 查看文件内容
```

**配套知识**

常见端口要记住：

| 端口 | 用途 |
|:---|:---|
| 80 / 443 | 网站服务 |
| 22 | SSH 远程登录 |
| 3389 | Windows 远程桌面 |
| 445 | Windows 文件共享 |

端口可以理解为设备的服务入口。

**今日目标**：会创建、编辑、查看文件，知道端口是什么。

### 第 3 天

**实操**

```bash
rm test.txt             # 删除文件
rm -rf test_dir         # 强制删除文件夹，不提示
cd /                    # 进入系统根目录
cd ~                    # 回到 root 家目录
```

**配套知识**

`ping` 是发一个数据包给目标，看有没有回复，用来判断设备是否开机、网络是否通。`arp` 是通过 IP 找设备的物理地址，内网扫描会用到。

**今日目标**：熟练删文件和切目录，理解 ping 和 arp 的作用。

### 第 4 天

**实操**

```bash
ip a                    # 查看本机 IP，看 inet 后面的地址
ping baidu.com -c 3     # 测试联网，只发 3 个包
netstat -tuln           # 查看本机开了哪些端口
```

**配套知识**

HTTP 是浏览器和网站服务器之间交流用的协议。你打开网页，就是发了一个 HTTP 请求；服务器返回页面内容，就是 HTTP 响应。

**今日目标**：会查 IP、测网络，明白上网就是收发 HTTP 数据。

### 第 5 天

**实操**

```bash
apt update              # 刷新软件源列表
apt install tree -y     # 安装 tree 工具
tree                    # 显示文件夹层级结构
```

**配套知识**

Linux 权限分三种：`r` 读、`w` 写、`x` 执行。root 拥有所有权限，普通用户受限制。

**今日目标**：会用 apt 装软件，理解 Linux 的权限分级。

### 第 6 天

**实操**

```bash
apt autoremove -y               # 卸载没用的依赖包
apt autoclean                   # 清理安装包缓存
systemctl status apache2        # 查看 Apache 服务状态
```

**配套知识**

常见的服务器服务有：Apache 和 Nginx 是网页服务器，MySQL 和 MariaDB 是数据库，SSH 是远程命令控制。

**今日目标**：会清理系统，知道网站、数据库、远程登录分别是什么服务。

### 第 7 天

**实操**

在 VMware 里给虚拟机拍一个快照，命名“第 7 天基础状态”。然后故意删错一个文件，用快照恢复。

**配套知识**

安全红线，必须记住：

- 只在本地虚拟机或靶场练习
- 不扫描、不攻击任何外网设备
- 不传播工具，不入侵他人设备

**今日目标**：养成拍快照的习惯，记住法律底线。

## 第 2 周：信息收集 + 服务识别

### 第 8 天

**实操**

```bash
netdiscover -r 192.168.x.0/24   # 扫描局域网内所有在线设备
```

**配套知识**

`192.168.1.0/24` 表示从 `192.168.1.1` 到 `192.168.1.255` 这个范围。能 ping 通、能扫描到的设备就是在线设备。

**今日目标**：会找靶机 IP。

### 第 9 天

**实操**

```bash
nmap 靶机IP          # 扫描常见端口
nmap -p- 靶机IP      # 扫描全部 65535 个端口
```

**配套知识**

开放端口越多，暴露的入口越多。开放端口可以访问，关闭端口无法连接。

**今日目标**：会做基础端口扫描。

### 第 10 天

**实操**

```bash
nmap -A -p- 靶机IP   # 扫全端口 + 系统版本 + 服务版本
```

**配套知识**

服务版本识别可以看出版本新旧，比如 Apache 2.4.41，版本越旧漏洞越多。nmap 也能判断对方是 Windows 还是 Linux。

**今日目标**：能看懂 nmap 的报告。

### 第 11 天

**实操**

```bash
apt install dirsearch -y    # 安装网站目录扫描工具
```

**配套知识**

网站后台常见路径有 `/admin`、`/login`、`/upload`、`/phpmyadmin`。

**今日目标**：装好目录扫描工具。

### 第 12 天

**实操**

```bash
dirsearch -u http://靶机IP   # 扫描网站隐藏路径和后台
```

**配套知识**

`robots.txt` 是网站告诉爬虫哪些路径不要看，反而会泄露一些敏感路径。

**今日目标**：会扫网站隐藏目录。

## 第 3 周：DVWA 漏洞 + Web 原理

### 第 13 天

**实操**

```bash
apt install apache2 mariadb-server php php-mysqli -y
systemctl start apache2 mariadb
```

**配套知识**

网站运行流程：浏览器 → Apache → PHP → MySQL。

**今日目标**：搭好 Web 运行环境。

### 第 14 天

**实操**

```bash
cd /var/www/html
git clone https://github.com/digininja/DVWA.git
chmod -R 777 DVWA
```

**配套知识**

DVWA 有四个难度：Low 无防护，Medium 简单过滤，High 较强防护，Impossible 基本打不动。入门从 Low 开始。

**今日目标**：搭好 DVWA 靶场。

### 第 15 天

**实操**

在 DVWA 的 SQL 注入页面输入：

```
' or 1=1#
```

**配套知识**

SQL 是数据库查询语言。`'` 用来打断原本的语句，`or 1=1` 让条件永远成立，`#` 注释掉后面内容。这样就能绕过账号密码登录。

**今日目标**：理解 SQL 注入的基本逻辑。

### 第 16 天

**实操**

重复练习 SQL 注入，尝试查看数据表。

**配套知识**

用户密码存在数据库里，SQL 注入就是想办法把这些数据查出来。

**今日目标**：熟练手工注入。

### 第 17 天

**实操**

在 XSS 页面输入：

```html
<script>alert(1)</script>
```

**配套知识**

JS 是在浏览器上运行的脚本。XSS 就是往页面里插入恶意 JS，让其他用户访问时执行。

**今日目标**：会测试 XSS 漏洞。

### 第 18 天

**实操**

在命令执行页面输入：

```
127.0.0.1; id
127.0.0.1; cat /etc/passwd
```

**配套知识**

`;`、`|`、`&&` 这些符号可以让服务器连续执行多条命令。如果程序没过滤这些符号，就能让服务器执行任意命令。

**今日目标**：理解命令执行的原理。

### 第 19 天

**实操**

在文件上传模块上传一张图片，查看上传后的路径。

**配套知识**

如果上传功能没做限制，可以上传木马文件，进而控制整个网站。

**今日目标**：理解上传漏洞的原理。

### 第 20 天

**实操**

把 SQL 注入、XSS、命令执行各练一遍。

**配套知识**

这些简单漏洞的本质都是同一个：服务器没有过滤用户的输入。

**今日目标**：把漏洞操作流程练熟。

## 第 4 周：Burp + 靶机渗透 + 提权

### 第 21 天

**实操**

浏览器设置代理 `127.0.0.1:8080`，打开 Burp Suite，开启拦截。

**配套知识**

Burp 位于浏览器和服务器之间，能截获所有请求。

**今日目标**：会抓包。

### 第 22 天

**实操**

抓 DVWA 的登录包，修改账号密码，重放请求。

**配套知识**

GET 请求参数在网址里，POST 请求参数在请求体里，相对隐蔽一些。

**今日目标**：会改包和重放。

### 第 23 天

**实操**

```bash
netdiscover -r 192.168.x.0/24
nmap -A -p- 靶机IP
```

**配套知识**

渗透工作中，信息收集占很大比重。信息越全，越容易找到漏洞。

**今日目标**：完成前期信息收集。

### 第 24 天

**实操**

```bash
dirsearch -u http://靶机IP
```

**配套知识**

webshell 是一个网页后门，通过它可以控制网站。

**今日目标**：找到漏洞入口。

### 第 25 天

**实操**

利用漏洞拿到 webshell，执行 `whoami` 查看当前权限。

**配套知识**

普通用户只能看自己的文件，root 能控制整个服务器。

**今日目标**：拿到网站权限。

### 第 26 天

**实操**

```bash
find / -perm -u+s -type f 2>/dev/null
```

**配套知识**

SUID 提权原理：程序自带 root 权限，普通用户运行它就能以 root 身份执行。

**今日目标**：学会 SUID 提权。

### 第 27 天

**实操**

```bash
sudo -l                      # 查看能免密执行的 root 命令
cat /root/flag.txt           # 提权后读取 flag
```

**配套知识**

sudo 配置错误时，管理员可能不小心给了普通用户直接提权的路径。

**今日目标**：完整拿下一台靶机。

## 收尾：MSF + 复盘

### 第 28 天

**实操**

```bash
msfconsole              # 启动 Metasploit
search mysql            # 搜索相关漏洞模块
```

**配套知识**

Metasploit 集成了大量漏洞利用工具，是渗透测试中常用的框架。

**今日目标**：熟悉 MSF 的界面和基本用法。

### 第 29 天

**实操**

```bash
use exploit/multi/handler
set lhost 你的KaliIP
run
```

**配套知识**

反弹 shell 是让服务器主动连接你，这样可以绕过防火墙对入站连接的拦截。

**今日目标**：会监听反弹 shell。

### 第 30 天

**实操**

不看教程，独立完成一遍完整流程：扫 IP → 扫端口 → 扫目录 → 拿 shell → 提权 → 拿 flag。

**配套知识**

整理自己的笔记，包括命令、payload、流程。后续方向可以考虑：多练靶机、学 Python、学绕过防护。

**今日目标**：达到入门水平。

---

## 总结

这 30 天里，你不只是在练 Kali，同时也把网络、Web、Linux、权限、漏洞原理过了一遍。学完之后，应该能独立完成一些基础操作，遇到问题也知道该往哪个方向查。

需要提醒的是，这份计划只是入门。真正的安全学习是长期的过程，靶场和真实环境的差距也很大。先把基础打牢，再考虑深入。

最后再说一次：只在本地虚拟机或授权靶场练习，不要碰任何不属于你的设备。
